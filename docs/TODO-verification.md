# 추가 검증 TODO (CEF OSR 브라우저 패널)

기존 34개 검증(`docs/VERIFICATION.md`)에 더해, "브라우저 패널로 실제 쓸 수 있는가"를 판정하기 위한 케이스.
**실행 방식** 표기: 🟢 헤드리스(창·포커스 없음, `SPIKE_HEADLESS`, 프레임은 PNG로 저장) 가능 / 🪟 gpui 창이 필요(포커스·입력 가로채기 있음, 자리 비울 때 실행) / 👤 사람이 직접.
우선순위: **P0** 브라우저로서 필수, **P1** 일상 사용 품질, **P2** 있으면 좋음.

## 실행 계획(제안)
1. 🟢 항목부터 헤드리스 하니스로 자동화(`headless.rs` 확장) — 창/포커스 없이 가능한 것이 대부분이다.
2. 🪟 항목은 자리를 비우는 시간에 묶어서 실행(`verify.sh --yes`), 결과는 `docs/VERIFICATION.md`에 누적.
3. 👤 항목은 체크리스트로 만들어 직접 확인.
